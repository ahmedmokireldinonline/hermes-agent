## 💡 نصائح تحسين الأداء

### للمستخدمين المحليين (Localhost)

#### 1. اختيار النموذج المناسب
```
المتطلبات: 4GB RAM ← استخدم Lite (4B/8B)
المتطلبات: 16GB RAM ← استخدم Balanced (14B/24B)
المتطلبات: 32GB+ RAM ← استخدم Quality (32B+)
```

#### 2. تحسينات التكوين
```env
# تقليل استهلاك الذاكرة
CONTEXT_LENGTH=2048          # بدلاً من 4096
BATCH_SIZE=1                 # معالجة مهمة واحدة
ENABLE_GPU=false             # إذا لم يكن لديك GPU

# تحسين السرعة
USE_CACHE=true
ENABLE_QUANTIZATION=true     # تقليل حجم النموذج
```

#### 3. استراتيجية التطبيق
```
1. ابدأ بـ MOCK_LLM=true للاختبار
2. انتقل لـ Lite profile للتطوير
3. استخدم Balanced فقط مع معالج جيد
4. Quality للإنتاج مع GPU
```
